# 街拍相机

原生 Android Kotlin + CameraX 相机，支持 Android 10 及以上。全屏取景，浮动控制放在画面边缘，AI 构图按钮紧邻手动快门。只使用默认后置相机的 1× 画面；1–8× 缩放与构图收紧均通过数字裁切实现，不切换超广角或长焦。删除了录像、前摄切换和普通构图模式。

## 拍摄与构图

- 点击「AI 构图」后自动发现候选主体，综合艺术表现力、叙事关系、视觉几何与清晰度选择最高权重项；不会固定选择中央或最大的物体。轻点取景画面仅用于对焦。设置入口在右上角。
- 寻找阶段在取景中心显示小幅环形动画；等待中仍可按快门，拍照会取消分析。
- AI 返回最终画幅内的主体位置及独立裁切宽、高后，沿粗直线半透明箭头移动手机，让目标圆圈与中央白点重合。箭头表示手机移动方向。
- 对齐稳定后自动收紧取景，确认自由裁切画幅后，连续平滑放大到目标倍率；起步和收尾使用更柔和的缓动。偏离或跟丢时暂停在当前倍率，重新对齐后继续，手势可随时接管。完成后提示「构图就绪」，快门始终手动按。裁切不锁定 4:3、16:9、正方形或原画幅比例，保留区域以细边框显示；结束引导后保留边框和已完成的裁切，照片按该区域输出。
- AI 失败时结束引导并显示具体错误，可重新点击构图；没有普通构图降级模式。
- 手动缩放、调整画质、打开 AI 设置或进入后台会结束引导。点击「结束」可主动停止，已经完成的缩放保留。
- 点按倍率、上下滑动或双指缩放均可调整构图。右侧变焦指示条显示当前倍率和对数刻度，可直接上下拖动，支持无障碍范围操作。滤镜包括原片、柔和、暖调、冷调与黑白，可调强度，预览与保存照片使用同一滤镜矩阵。
- 照片保存到 `Pictures/街拍相机`。CameraX 共享 ViewPort 与软件裁切保证保存画幅与全屏预览对应；全屏画幅和高倍率会减少最终像素数。「高画质」是设备支持范围内的请求，不承诺所有手机输出相同像素数。

交互方向参考 [OPPO Find X10 的 LUMO 灵感构图](https://www.oppo.com/cn/smartphones/series-find-x/find-x10/)，箭头、对齐圆圈和主摄数字裁切由本应用实现。

## AI 设置

支持 DeepSeek、小米 MiMo、OpenAI、阿里云百炼、硅基流动及自定义 OpenAI Chat Completions 兼容接口。供应商分别保存地址、模型名和 Key，模型必须支持图片输入。基础地址或完整 `/chat/completions` 地址均可，使用 HTTPS。

本地多角点光流负责持续跟踪；AI 只接收一张最长边不超过 512 px 的 JPEG，返回建议后不持续上传画面。实时提示词结合主体、留白、对称、引导线、空间层次与叙事，输出一条短建议；不会让用户在取景时阅读评分和长篇分析。请求超时约 20 秒。DeepSeek / MiMo 请求关闭深度思考，限制输出长度以减少等待；实际速度取决于网络和供应商。

Key 使用 Android Keystore AES-GCM 加密，设置窗口禁止截图。留空保留当前 Key，填写新值替换，也可主动删除。旧供应商配置继续保留。应用直连所选接口，费用由供应商计收。

接口依据：[DeepSeek 图片输入](https://api-docs.deepseek.com/guides/vision/)、[MiMo 图片理解](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/multimodal-understanding/image-understanding)、[OpenAI 视觉接口](https://developers.openai.com/api/docs/guides/images-vision)、[百炼视觉接口](https://www.alibabacloud.com/help/en/model-studio/vision)、[硅基流动视觉接口](https://docs.siliconflow.cn/docs/userguide/capabilities/vision)。

## 验证与构建

单元测试覆盖跟踪、逐步裁切、几何映射、AI 请求与错误、缩放运动和滤镜矩阵。Android 模拟器用于检查全屏界面、原生控制、字体缩放、横屏、寻找/引导状态及实际照片保存。调试版的 `UiPreviewActivity` 只渲染模拟的 AI 状态，不调用接口，发布版不包含它。没有使用真实 Key 调用付费 API；仍需真机验证主摄选择、弱光跟踪、端到端 AI 性能与设备兼容性。

需要 JDK 17+ 与 Android SDK 36.1。

```bash
./gradlew testDebugUnitTest assembleDebug lintDebug
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`，不再限制为 ARM64 单一架构。

## 自由裁切几何

AI 返回当前上传画面的保留宽、高 `u,v`（0–1，独立选择，无固定比例）。分解为等比放大 `k=1/max(u,v)` 和最终画幅保留比例 `a=u*k,b=v*k`。连续放大后再按 `a,b` 裁切，避免把图像拉伸。若剩余放大倍数为 `r`、最终主体位置为 `t`，裁切前对齐位置是 `0.5+(t-0.5)*a/r`（纵轴使用 `b`）。输出像素数约为 `N_viewport*a*b/z²`。若触及最大缩放，保留画幅形状并放宽裁切范围。横竖屏保存按旋转角度交换原始像素轴。旧模型返回的 `crop_scale` 仍可解析，此时沿用原画幅形状。

## 自动主体与缓动

AI 对最多两个可见候选方案提供艺术兴趣、叙事、几何关系和清晰度的主观权重；程序按 `0.45*art+0.25*story+0.20*geometry+0.10*clarity` 选取最高有效方案。阴影、倒影、剪影、色彩与几何关系都可成为主体。等待期间本地跟踪全景运动，把返回点映射到当前画面；明显变化或无法可靠跟踪时提示重新寻找。权重和艺术判断来自视觉模型，尚未使用真实 Key 验证审美效果。自动模式输出上限 640 token，保留旧单方案协议兼容。

自动放大在对数倍率空间以五次平滑曲线 `s(t)=10t³-15t⁴+6t⁵` 完成，时长 `max(0.5秒,1.05*abs(ln(z_goal/z_start)))`；手势指数响应系数 70，按钮临界阻尼系数 14。右侧指示条的每次倍率翻倍对应相同距离。系统关闭动画时自动放大直接到位。
