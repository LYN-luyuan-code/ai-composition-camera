# Xiaomi 14 滤镜对齐

目标来自用户确认：Xiaomi 14，整批滤镜效果，而非只优化一个预设。
当前应用版本 v0.3.0 的多数预设由通用影调与偏色配方生成，尚未完成原机对照标定；本记录不代表已有校准结果。

## 已核实的参考

- Xiaomi 14 官方产品页：https://www.mi.com/xiaomi-14
- Xiaomi 14 产品页完整内容的检索入口：https://www.mi.com/xiaomi-14?awc=23677_1698347020_87f7cb8a5428ae2e8e2b971c7992c087
- Leica 对 Xiaomi 14 的官方说明：https://leica-camera.com/en-US/news/xiaomi-14-series-latest-leica-camera-features

官方产品页明确区分两种摄影画质（徕卡经典、徕卡生动）与六款滤镜（徕卡自然、徕卡鲜艳、徕卡单色HC、徕卡单色、徕卡漂棕、徕卡单色蓝）。截至本次核对，没有取得可以验证来源的 Xiaomi 14 原厂 .cube 文件，公开描述不作为数值调色配方。

这份官方展示清单不是所有后续相机/相册版本的穷举。正片、负片、黑金、繁花如梦、赤霞红、远山青等，以用户当前 Xiaomi 14 的实际同名效果为对照；未核实的条目不宣称属于原机。哈苏参考预设及有独立作者来源的电影60s/80s，也不冒充 Xiaomi 14 原版。

## 待取得的标定数据

优先一组固定场景：本应用原片、小米原相机原片、原相机各个滤镜的成片。记录相机版本、经典/生动画质、滤镜名称和强度。固定主摄1×、机位、光线和曝光/白平衡，关闭美颜，提供原始照片文件，避免聊天软件压缩或屏幕显示色彩影响对照。

场景最好同时有中性灰/白、肤色或暖色物体、植物绿、天空蓝、暗部和高光。后续用不同场景作独立验证；同一张拟合样张不能同时充当还原效果验证。

在取得对照前保留 v0.3.0 的预设与导入功能，不凭名称重新猜数值，也不发布声称完成原机还原的新安装包。拿到数据后再分别拟合影调和颜色映射，按实际对照评估误差；空间效果、曝光与局部处理的差异需另外判断，不能由一张颜色表冒称完全复现。
